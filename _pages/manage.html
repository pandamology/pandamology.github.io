第一次使用：怎么完成更新？
  1. 在下面选择要修改的内容，直接填写。新增论文、报告或课程，点击“新增记录”。
  2. 点击“下载更新文件”，得到名为 cv.json 的文件。
  3. 点击“打开 GitHub 上传”，用你的 GitHub 账号登录，将刚下载的文件拖入上传框。文件名必须是 cv.json，如果浏览器加了数字后缀，请先改回这个名字。
  4. 页面下方选择提交到 master，点击 Commit changes。如果出现替换同名文件的提示，确认替换。
  5. 在 发布进度中等待最新一次“Build website and CV”变绿，再查看主页和CV。

填写和下载不会立即修改网站；GitHub 提交后才会发布。你无需上传 PDF。新增内容可能使 PDF 自然增加页数。

发布失败时线上保留上一次成功版本。可以回到这个页面修正资料后重新提交；旧资料可在 GitHub 的文件历史中找回。

在“CV 栏目与顺序”中可新增栏目、修改栏目标题、隐藏或调整顺序。这些设置作用于 PDF CV；首页及 Publications、Talks、Teaching 的展示设置保持独立。隐藏不会删除资料，隐藏内容仍保存在公开仓库中。新增栏目采用“时间、标题、机构、补充说明”的通用格式，发布后出现在 CV PDF 内。

未下载的修改只保留在当前页面，关闭或刷新前请先下载。资料文件中的网页链接仍用于其他页面，但不会成为 PDF 的超链接。
